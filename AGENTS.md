# Contributor and agent instructions

Guru is currently a documentation-only project for Valio Aimo's Trusted Trade Agents challenge. Read CHALLENGE.md, ARCHITECTURE.md, TEAM.md, TODO.md and CHANGELOG.md before work.

- Do not claim that a design, agent, API, mock integration, test, metric or deployment already works unless verified.
- Use only synthetic/mock systems. Never commit the resource portal password, API key, test-account credentials, customer data or unapproved downloaded resources.
- Determine lane A/B/C from the branch and TEAM.md. Keep changes in your lane; agree shared G1–G7 contracts together before implementation.
- Use feature branches and PRs. Review shared interfaces with affected teammates. Do not force-push or rewrite shared history.
- Update CHANGELOG.md with every meaningful change and docs/DECISIONS.md for decisions. Keep TODO.md current.
- Enforce authority outside the LLM. Never silently relax a hard dietary/allergen constraint or accept the agent's own approval.
- Runtime, framework and actual sponsor API schemas remain unselected/unverified. Do not invent setup commands or vendor endpoints.
